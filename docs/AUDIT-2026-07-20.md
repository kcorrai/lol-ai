## What the codebase already does well

Worth recording, because these were checked and found genuinely clean rather than merely unexamined:

- **Zero `any`** across 787 TS/TSX files. Zero `console.*` outside the logging service. Zero
  TODO/FIXME. One `eslint-disable`, with a written justification.
- **No cross-domain service imports**, no Riot API calls outside `src/domains/riot/`, no AI SDK usage
  outside `src/lib/ai/`. The architecture rules in CLAUDE.md are actually being followed.
- **Billing webhook is correctly verified** — raw body, HMAC-SHA256, `timingSafeEqual`. Checkout
  resolves variant IDs server-side from env, so price/plan cannot be set by the client.
- **Cron routes are `CRON_SECRET`-gated.** Admin routes check `ADMIN_EMAIL` and fail closed when it is
  unset.
- **Ownership checks are consistent**: `assertOwnsRiotAccount` / `assertTeamAccess` / `assertOwnerAccess`
  are applied at the service layer, so route handlers cannot forget them.
- **CSP is real and scoped** (per-source allowlists, `frame-ancestors 'none'`, `form-action 'self'`).
- **CI runs lint, typecheck, unit and e2e.** `tsconfig` is strict with no weakening flags, and
  `next.config.mjs` does not set `ignoreBuildErrors`.
- **`.env*` is correctly gitignored**; no secrets in committed source.

## Claims that did not survive verification

Recorded so they are not chased again:

- **"IDOR vulnerabilities in the API surface."** None found. The pass covered 71 of 122 routes and
  reported no IDOR; spot-checks of the remainder matched the same `withAuth` + ownership-assert
  pattern. Coverage was incomplete, so this is "none found", not "none exist" — but nothing indicates
  a systemic gap.
- **"`app/api/admin/ai-cost` is unauthenticated."** False positive from a grep that missed
  `withAdminAuth` (the substring `withAuth` does not occur in `withAdminAuth`). The route is properly
  gated.
- **"`promote-team` is a privilege-escalation hole."** Overstated. It requires either `ADMIN_EMAIL`
  session or `CRON_SECRET`. The real, smaller issue is that it hand-rolls auth instead of using
  `withAdminAuth`, and leaks `err.message` to the client. Worth tidying, not a vulnerability.
- **"`.env.local` contains exposed secrets — rotate immediately."** The file is gitignored and not in
  git history. Real credentials on a developer machine in an ignored file is normal practice, not an
  incident. (The review pass did print those values into its own transcript, which is a reason to
  scope future automated passes away from `.env*` files.)
- **"Coverage is 10-15% against a 70-90% requirement."** Extrapolated from file-existence counts, not
  from `vitest --coverage`. The specific untested files in TASK-257 were verified individually; the
  percentage was not. Run `npm run test:coverage` before quoting a number.
- **"App pages exceed the 80-line limit by ~229 lines."** Wrong limit applied — `page.tsx` and
  `PageClient.tsx` are components (200), not API route handlers (80). Corrected table in TASK-260.
- **"`Date.now()` in render causes hydration mismatches"** (4 components). Plausible but unverified —
  it depends on whether each component is actually server-rendered. Not filed as a task until
  someone confirms a real mismatch warning in the browser console.
